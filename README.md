# Alpaca Algorithmic Trading Platform

Python-based algorithmic trading platform with market data ingestion, risk controls, backtesting, and real-time monitoring.

This repository documents a service-oriented trading infrastructure prototype for paper trading and reproducible simulation with Alpaca. It implements the path from market data to strategy signals, risk-gated order intents, broker execution, persisted fills, API access, and monitoring.

The project focuses on the system around the signal: event transport, typed contracts, risk checks
